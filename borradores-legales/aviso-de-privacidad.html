1. Responsable

El responsable del tratamiento de los datos personales relacionados con este sitio es José Jaime Díaz Ramos, quien desarrolla el proyecto bajo la identidad pública DMFN – Díaz Mindfulness, con ubicación en Tecate, Baja California, México.

Correo de contacto para privacidad: contacto@aquiyahoralive.com.

2. Datos personales que pueden tratarse

  • Contador de “Me gusta”: las dos reflexiones que actualmente tienen contador generan o recuperan un identificador aleatorio tipo UUID, guardado en el navegador mediante localStorage bajo la clave dmfn-voter-id. La API recibe ese identificador y el nombre técnico de la reflexión; la base de datos D1 registra el identificador de votante asociado a la reflexión. El contador no pide nombre, teléfono ni correo.
  • Contacto voluntario: si la persona escribe al correo o inicia una conversación por WhatsApp, los datos que decida incluir serán tratados para responderle. El mensaje se gestiona mediante el proveedor correspondiente, no mediante un formulario de este sitio.
  • Datos técnicos de conexión: el proveedor de alojamiento y seguridad puede procesar información técnica de las solicitudes para operar, mantener y proteger el sitio, conforme a sus propias condiciones y políticas.

3. Finalidades

Los datos se utilizan para mantener el funcionamiento del sitio, registrar y mostrar reacciones, reconocer el mismo identificador de navegador en una reflexión y responder mensajes que las personas envíen voluntariamente. El identificador ayuda a evitar que el mismo UUID se registre más de una vez para una misma reflexión, pero no verifica la identidad de una persona ni garantiza un voto por persona: se puede generar otro identificador al borrar el almacenamiento o usar otro navegador o dispositivo. Actualmente no se observó integración de CAPTCHA/Turnstile ni limitación de frecuencia en el código revisado.

En los archivos revisados no se encontró un sistema funcional de registro de cuentas, comentarios públicos, formulario web de contacto, herramientas de analítica como Google Analytics ni código propio que escriba cookies mediante document.cookie. El menú muestra un enlace “Acceso miembros”, pero en la página de inicio apunta a un ancla #miembros y no se encontró un flujo de autenticación asociado. El sitio no solicita cuentas de usuario ni datos sensibles mediante el contador.

4. Almacenamiento y proveedores

El contador utiliza localStorage en el navegador y una base de datos D1 vinculada a Cloudflare Pages para registrar UUID y reflexión. La API valida que la reflexión pertenezca a una lista permitida y que el identificador tenga formato UUID; las consultas SQL usan parámetros. El código consultado no establece un plazo de conservación ni una rutina automática de eliminación de los registros de votos. El sitio está alojado en Cloudflare Pages; Cloudflare puede tratar datos técnicos de conexión y seguridad conforme a la configuración del servicio y sus propias condiciones. Es necesario confirmar en el panel y en la documentación del proveedor qué registros se generan, cuánto tiempo se conservan y qué cookies técnicas, si las hay, se utilizan.

La página de contacto ofrece un enlace de correo y un enlace a WhatsApp. El sitio no contiene actualmente un formulario de contacto: al enviar un correo o abrir WhatsApp, la persona utiliza su aplicación o el servicio externo y decide qué información incluir. En dos reflexiones se cargan imágenes de cartas desde servidores de Wikimedia; al abrir esas páginas, el navegador solicita esos archivos a Wikimedia, que puede recibir datos técnicos de conexión como la dirección IP y datos del navegador. Esos terceros aplican sus propios avisos y prácticas de privacidad.

5. Derechos ARCO y contacto

La persona titular puede solicitar información sobre sus datos y, cuando proceda conforme a la legislación aplicable, ejercer sus derechos de acceso, rectificación, cancelación u oposición (ARCO), así como revocar su consentimiento en los casos que correspondan, escribiendo a contacto@aquiyahoralive.com. La solicitud deberá permitir identificar a la persona solicitante y describir claramente el derecho que desea ejercer. Se le informará si se requiere documentación adicional.

6. Conservación y solicitudes de eliminación

El código revisado no define un periodo de conservación de los UUID de votos ni un mecanismo automático de borrado. Antes de publicar la versión definitiva, el responsable deberá establecer y documentar un criterio de conservación y un procedimiento para atender solicitudes procedentes de eliminación, cuando legalmente corresponda.

7. Cambios al aviso

Las actualizaciones de este aviso se publicarán en esta sección, indicando la fecha de revisión. La versión definitiva deberá incluir el domicilio completo del responsable y describir con precisión las tecnologías y proveedores efectivamente utilizados.
